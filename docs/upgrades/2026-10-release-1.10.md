# Upgrade notes: 1.10.0

Separate customer accounts per channel (an option) and gift cards sold as products. Two migrations. Plugin and theme contracts stay compatible: cart lines and products have new optional fields.

```bash
composer update pnscripts/pn-shop-core --with-all-dependencies
php artisan pnshop:update
php artisan optimize
```

## Migrations

- `users.account_scope` (0 for every existing customer: shared accounts) and `channels.separate_accounts` (off for every existing channel). The unique index on `users.email` becomes unique on `email` + `account_scope`.
- `products.is_gift_card`, `cart_lines.gift_card_recipients`, `order_items.gift_card_recipients`, `gift_cards.order_item_id` and `gift_cards.message`.

Nothing changes until you use them: existing channels keep shared accounts, and no product is a gift card.

## Required actions

- **Themes:** rebuild non-default themes (`npm run build:theme -- <vendor/name>`, then `php artisan pnshop:theme publish <vendor/name>`) for the gift card fields on the product page and the recipients in the cart. Older themes can still sell gift cards; the cards then go to the buyer.
- **Code that looks customers up by email:** with separate accounts an email can belong to two customers. Plugins should go through `PnShop\Customer\CustomerAccounts` (`scope()`, `credentials()`, `uniqueEmail()`) instead of `User::where('email', …)->first()`.

## Behaviour changes

- **Separate accounts** are chosen when a channel is created and cannot be changed later. The default channel always uses the shared accounts.
- **Gift card products** are never discounted and never paid with gift cards or store credit. An order of only gift cards asks for no delivery method.
