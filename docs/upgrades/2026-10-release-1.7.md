# Upgrade notes: 1.7.0

A PayPal payment plugin, and store emails that are sent without a queue worker. No migrations. Plugin and theme contracts stay compatible.

```bash
composer update pnscripts/pn-shop-core --with-all-dependencies
php artisan pnshop:update
php artisan optimize && php artisan queue:restart
```

## PayPal

The plugin is in `extensions/pnshop/paypal` in new shops (`composer create-project pnscripts/pn-shop`). Existing shops can copy that folder from the [`pnscripts/pn-shop`](https://github.com/pnscripts/pn-shop) repository into their own `extensions/pnshop/`. Then:

1. install and enable it in Admin → Extensions;
2. follow its README: credentials, the webhook, and a payment method using the *PayPal* gateway.

## Store emails

- **The cron line is enough:** with the usual `* * * * * php artisan schedule:run` cron line, the scheduler now also sends queued emails every minute. On shared hosting no queue worker is needed.
- **With a queue worker:** a server running `queue:work` keeps working as before. Set `PNSHOP_QUEUE_FROM_SCHEDULER=false` if you prefer the scheduler not to work the queue.
- **Failed sends:** a refused send is retried 5 times (after 1, 5, 15 and 60 minutes) before it is logged and kept in `failed_jobs`.

See [deployment](../installation/deployment.md).
