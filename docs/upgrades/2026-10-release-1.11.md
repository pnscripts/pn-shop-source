# Upgrade notes: 1.11.0

Strict authorization in the admin, extension points for prices, plugin pages and money text, and six optional plugins for Bulgarian and EU requirements. No core migrations.

```bash
composer update pnscripts/pn-shop-core --with-all-dependencies
php artisan pnshop:update
php artisan optimize
```

## Required actions

- **Plugins with admin screens:** the admin now runs in strict authorization mode. Give every model of your plugin's resources and relation managers a policy (`Gate::policy()` in `bootPlugin()`; `PermissionPolicy` and `ReadOnlyPolicy` help). A screen without one now shows an error instead of being open to every staff account.
- **Themes:** rebuild non-default themes (`npm run build:theme -- <vendor/name>`, then `php artisan pnshop:theme publish <vendor/name>`). Themes with their own product card or product page should strike through `wasPrice()` from `@/lib/prices` instead of `price`; until then they keep striking through the regular price.

## Behaviour changes

- **Admin:** payments, refunds, shipments, order history, stock movements, balance ledgers, page revisions and the activity log can no longer be changed through generic admin actions (they never offered any; now it is enforced).
- **Product data** has a new field `prior_price` (storefront props and Store API). It equals the regular price while a reduction is shown, unless a plugin such as `pnshop/prior-price` supplies another.

## New plugins

Copy them from the released skeleton's `extensions/pnshop/` if your shop was created before 1.11, then install and enable the ones you need (`php artisan pnshop:plugin install <id>` and `enable <id>`): `pnshop/prior-price`, `pnshop/withdrawal`, `pnshop/bg-euro`, `pnshop/bg-n18`, `pnshop/econt`, `pnshop/speedy`. Their READMEs list the settings and what the shop still has to do itself.
