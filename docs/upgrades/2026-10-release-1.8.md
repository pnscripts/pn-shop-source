# Upgrade notes: 1.8.0

A visual page editor. No migrations. Plugin and theme contracts stay compatible.

```bash
composer update pnscripts/pn-shop-core --with-all-dependencies
php artisan pnshop:update
php artisan optimize
```

## Visual page editor

*Design* on a page (Admin → Content → Pages) opens its blocks next to a live preview. Staff who may edit pages can use it; nothing changes in how pages are stored. See [pages and blocks](../cms/pages-and-blocks.md#visual-editor).

## Required actions

- **Rebuild themes:** the preview uses the active theme's own components. Non-default themes must be rebuilt and republished for live changes and click-to-edit in the preview:

  ```bash
  npm run build:theme -- <vendor/name>
  php artisan pnshop:theme publish <vendor/name>
  ```

  With an older theme build the preview shows the saved page, and the editor itself works as before.
- **Route cache:** the preview has a new route (`/preview/pages/{id}/design`); `php artisan optimize` rebuilds the cache.
